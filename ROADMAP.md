# План BotForge

Работа разделена на семь дневных этапов. Это порядок следующих сессий разработки, а не автоматический запуск по расписанию. Сроки подключения экспорта зависят от готовности API.

| День | Объём | Результат |
| --- | --- | --- |
| 1 | Минимальный дизайн, навигация, проекты | Готово: создание, поиск, открытие, удаление с подтверждением, localStorage, адаптивный каркас и иллюстрация конструктора |
| 2 | Визуальный редактор | React Flow, добавление и перемещение блоков, свойства, связи, отмена действий |
| 3 | Данные проекта | Формат схемы, сохранение, переменные, переименование и дублирование проектов |
| 4 | Предпросмотр | Команды, кнопки, ввод, условия, сброс и ограничение циклов |
| 5 | Поведение | Автоответы, /help, /cancel, история, таймер и защита |
| 6 | Экспорт | Согласование API, проверка, список файлов, ZIP и ошибки |
| 7 | Проверки | Мобильный редактор, доступность, основные сценарии и исправления |

## Ограничения первого дня

Схема и чат демонстрируют только дизайн. Разделы следующих этапов явно обозначены. Нет API, реального Telegram, генерации кода, ZIP, авторизации и автосохранения на сервер. Нет токенов ботов и внешних зависимостей. Начальный экран не содержит вымышленных пользовательских проектов.

## Проверки первого дня

`npm run check` проверяет синтаксис JavaScript. HTTP-проверка: `/`, `/app.js`, `/style.css` возвращают 200, неизвестный путь возвращает 404.

Ручной сценарий: создать проект, найти по названию, открыть макет, вернуться, обновить страницу и удалить с подтверждением. Проверить ширины 1440, 1024 и 390 px. Ошибка localStorage не должна закрывать форму и стирать введённое название. Пользовательские названия вставляются через textContent.
