## Разделение ответственности

Фронтенд отвечает за интерфейс, редактирование схемы, локальный предпросмотр и отображение ошибок. Бэкенд отвечает за хранение, серверную проверку проекта, генерацию исходников и ZIP. Временный источник данных и API должны использовать одинаковую модель проекта. Статус «Сохранено» при подключённом API показывается только после успешного ответа сервера.

Первая версия поддерживает Telegram, экспорт на Python и JavaScript. ВКонтакте, Discord, загрузка медиа, интеграции и хостинг ботов идут после этого плана. Авторизация и совместное редактирование не входят в исходный объём; до отдельного решения об управлении доступом сервер предназначен для локального запуска или закрытого окружения.

## Текущее состояние

Обновлено: подключено локальное API проектов, атомарное JSON-хранилище и проверка структуры/сценария. Фронтенд редактирует семь типов блоков, переходы через свойства, переменные и основные настройки поведения. Есть сохранение, перенос старых браузерных проектов, дублирование и конфликт ревизий. Подробности и контракт — в README.md.

Редактор дополнен React Flow: линии через точки, перемещение с сеткой, масштаб, миникарта и инспектор справа. Координаты и связи сохраняются через API.

Добавлены локальный предпросмотр и экспорт ZIP на Python/JavaScript/TypeScript/Go через Telegram Bot API без внешних библиотек. В движках работают команды, кнопки, ввод, переменные, условия, автоответы, история, таймер, лимит частоты и защита повторных нажатий.

Пока не готовы: undo/redo, хранение сессий экспортированных ботов после перезапуска и проверка на реальном Telegram с токеном. Добавлены Go и TypeScript; новые генераторы проверяются сборкой и сопоставлением с предпросмотром; формат проекта остаётся независимым от языка.

Пройдены синтаксические и автоматические HTTP/валидационные проверки. В браузере подтверждён путь создания проекта, добавления блоков, перехода, сохранения и восстановления. Полная приёмка ТЗ ещё не пройдена.

## Приёмка

- Создание, поиск, переименование, дублирование и удаление проекта с подтверждением.
- Сценарий /start → приветствие → две кнопки → разные ответы.
- Ввод имени, подстановка переменной и обе ветки условия.
- Автоответы, /help, /cancel, сброс /start и отключение старых кнопок.
- Режимы истории, таймер, повтор вопроса и защита от повторных действий.
- Сохранение и восстановление содержимого, координат, связей и настроек через API.
- Ошибки проверки с переходом к блоку; сбой API не стирает изменения.
- Просмотр файлов и скачивание ZIP для Python и JavaScript.
- Основные действия на телефоне и доступность с клавиатуры.

Минимальные автоматические проверки: переходы по кнопкам, ввод и условия, автоответы, сброс, ограничение циклов, сериализация и восстановление схемы. Для API дополнительно проверить валидацию, хранение и экспорт; для исходников проверить синтаксис обоих языков. Основной путь проверяется также вручную.

## Коммиты

Все изменения одного дневного этапа собираются в один коммит после проверок. Названия уникальные, на русском, из 2–3 слов и описывают выполненную работу. Изменение плана оформляется отдельным коммитом.
