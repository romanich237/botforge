# BotForge

Конструктор Telegram-ботов. Node.js 20+, зависимости устанавливаются через npm.

```sh
npm install
npm start
# http://localhost:3000
npm run check
npm test
```

## Реализовано

- Серверные проекты: создание, поиск, открытие, переименование, дублирование, удаление.
- Редактор React Flow: свободное перемещение блоков с привязкой к сетке, линии через точки, отдельные выходы кнопок и условий, масштаб, перемещение поля, миникарта и показ всей схемы. Свойства справа; переходы также доступны через список целевых блоков. Перетягивание нового соединения с занятого выхода заменяет старую связь. Оба конца существующей линии можно переподключать перетаскиванием. Занятый выход и отпускание на пустом поле сохраняют старую связь. Удаление связей — в списке «Связи».
- Поиск блоков по типу, ID, команде, тексту, описанию и подписям кнопок. Выбор результата выделяет блок и центрирует схему; Enter открывает первый результат, Escape очищает запрос. На телефоне открывается вкладка «Схема», свойства доступны в соседней вкладке.
- Перестановка кнопок «Выше» / «Ниже» в свойствах сохраняет ID и переходы; новый порядок используется в предпросмотре и экспорте.
- Предпросмотр в конструкторе и разделе «Тестирование»: команды, обе клавиатуры, ввод с проверками, переменные, условия, подсветка текущего блока, сброс и остановка циклов.
- Настройки поведения действуют в предпросмотре и экспорте: автоответы, /help, /cancel, сброс /start, старые кнопки, история, повтор вопроса, статус печати, таймер и ограничение частоты.
- Экспорт текущего черновика через API: просмотр файлов, копирование и скачивание ZIP на Python, JavaScript, TypeScript и Go.
- Ручное сохранение, ошибки без стирания черновика, предупреждение перед закрытием, защита от устаревшей записи из другой вкладки.
- Серверная проверка команд, переменных, обязательных полей и переходов; предупреждения о недостижимых блоках.
- Перенос прежних проектов из localStorage по отдельной кнопке. Переносится название: старый прототип не сохранял схемы.

## Хранение

Проекты хранятся в `data/botforge.sqlite` через better-sqlite3. `DATA_DIR` задаёт другой каталог, `PORT` — порт (по умолчанию 3000). SQLite работает в режиме WAL с `synchronous=FULL`, ожиданием блокировки до 5 секунд и индексом по времени изменения. Обновление документа и ревизии выполняется транзакционно; устаревший черновик получает HTTP 409. Общей очереди запросов больше нет. Формат проекта и API сохранены.

При первом запуске существующие `DATA_DIR/<uuid>.json` автоматически переносятся одной транзакцией. Содержимое, ID, ревизии, координаты, связи и настройки сохраняются. Исходные JSON-файлы остаются на месте. Если проект повреждён, запуск завершается с ошибкой, весь импорт откатывается: исправьте указанный файл и повторите запуск. Маркер успешного переноса хранится в БД; последующие запуски не импортируют старые файлы повторно и не восстанавливают удалённые проекты.

Перед первым обновлением сделайте копию каталога данных. Для резервной копии SQLite остановите все процессы BotForge и скопируйте весь `DATA_DIR`, включая файлы `botforge.sqlite-wal` и `botforge.sqlite-shm`, если они присутствуют. Не копируйте только основной файл работающей WAL-базы. Для восстановления остановите приложение и восстановите каталог целиком из одной копии. Старые JSON — снимок до миграции, новые правки в них не записываются.

Встроенный HTTP-сервер слушает только `127.0.0.1`. Для публикации используется Nginx с HTTPS и обязательным паролем: см. deploy/README.md. Это общее пространство команды; отдельных аккаунтов и разграничения доступа к проектам пока нет. База предназначена для локального диска одного сервера; поддержка нескольких серверов с общим сетевым диском не заявляется.

## API

Ответы API — JSON, кроме скачивания ZIP; ошибки `{ "message": "..." }`. Максимальное тело запроса — 1 МиБ.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/projects` | Список проектов |
| POST | `/api/projects` | Создать; достаточно `{ "name": "Магазин" }` |
| GET | `/api/projects/:id` | Открыть |
| PUT | `/api/projects/:id` | Сохранить полный проект с текущим `revision` |
| DELETE | `/api/projects/:id` | Удалить |
| POST | `/api/projects/:id/duplicate` | Дублировать, тело `{}` |
| POST | `/api/projects/:id/validate` | Проверить переданный полный черновик |
| POST | `/api/projects/:id/export` | Проверить и получить файлы, тело `{ project, language }` |
| POST | `/api/projects/:id/export/zip` | Проверить и скачать ZIP, тело `{ project, language }` |
| GET | `/api/ai/status` | Доступность, модель и имя провайдера без ключа |
| POST | `/api/projects/:id/ai` | Создать предложение сценария, тело `{ project, prompt }`, без сохранения |

Модель: `version: 1`, `id`, `revision`, `name`, `description`, `platform: "telegram"`, `updatedAt`, `nodes`, `edges`, `variables`, `behavior`.

Блок: `{ id, type, x, y, data }`. Типы: `start`, `command`, `text`, `buttons`, `input`, `condition`, `end`. Связь: `{ id, source, output, target }`; выход `next`, `yes` / `no` или ID кнопки. Переменная: `{ name, type: "text" | "number", initial }`. Ошибка проверки: `{ code, message, nodeId?, field? }`; ответ `{ valid, errors, warnings }`. Неполные сценарии можно сохранять; нарушенные ссылки и структуры отклоняются. Конфликт ревизии — HTTP 409.

## Ещё не реализовано

Undo/redo, медиа, интеграции и хостинг ботов. Координаты блоков и соединения сохраняются на сервере. Масштаб и положение камеры сохраняются при редактировании в текущей сессии интерфейса.

Формат сценария независим от языка. Поддерживаются Python, JavaScript, TypeScript и Go. Дополнительные языки добавляются отдельными генераторами после проверки совпадения поведения. Импорт произвольных исходников обратно в блоки не предусмотрен.

## Проверки

`npm test`: HTTP API, серверное восстановление, конфликт ревизий, дублирование, удаление, некорректные связи, запрет стороннего Origin и проверки схемы. В браузере проверены создание проекта, блоки старт/текст, переход, сохранение, восстановление после перезагрузки и успешная проверка. Все разрешения экрана и полный набор форм вручную ещё не проверены.

## Сборка редактора

`src/canvas.jsx` собирается esbuild в `public/canvas.js` и `public/canvas.css`. `npm start` автоматически запускает сборку; после изменения JSX используйте `npm run build` и обновите страницу. React Flow поставляется локально, CDN не нужен.

## Обучение и адаптивность

Кнопка «Помощь» открывает пять шагов обучения. Раздел «Как пользоваться» содержит справку и ответы на вопросы. Учебный пример создаётся отдельным проектом с четырьмя блоками и двумя ветками; существующие проекты не заменяются. Чек-лист под редактором показывает наличие старта, сообщения, связи и несохранённых изменений; это подсказка, а не полная проверка сценария.

На ширине до 650 px доступны вкладки «Блоки», «Схема», «Свойства» и «Тест». Выбрать блок и настроить переход можно через списки без перетаскивания. На широком экране панели показываются одновременно. Проверены компоновки 390, 1024 и 1440 px; физические сенсорные устройства и экранный диктор не проверены.

## Предпросмотр и экспорт

В конструкторе нажмите «Предпросмотр» или откройте «Тестирование». Диалог выполняется локально без токена и отправки сообщений в Telegram. Enter отправляет, Shift+Enter переносит строку. После изменения сценария нужно перезапустить тест; сохранение не обязательно. Режим истории изменяет предыдущий ответ; обновление с нижней клавиатурой заменяется новым сообщением с предупреждением. Предпросмотр не проверяет реальные права Telegram на удаление.

В «Экспорте» выберите Python, JavaScript, TypeScript или Go, нажмите «Проверить и подготовить код», затем «Скачать ZIP». Ошибки схемы блокируют экспорт (HTTP 422, `{ valid, errors, warnings, files: [] }`); каждую ошибку можно открыть в конструкторе. `language` принимает `python`, `javascript`, `typescript` или `go`. ZIP включает `bot.py`/`bot.js`, `runtime.py`/`runtime.js`, `project.json`, `.env.example`, `.gitignore`, `README.md`. Имена файлов фиксированы, пользовательские данные записываются в JSON, не вставляются в исполняемый код.

Для запуска архива нужен Python 3.10+ или Node.js 20+; внешние библиотеки боту не нужны. Скопируйте `.env.example` в `.env`, локально заполните `BOT_TOKEN` от @BotFather и выполните `python3 bot.py` или `node bot.js`. Токен не вводится на сайте. Поддерживаются личные чаты и long polling. Наличие webhook вызывает понятную ошибку, без автоматического удаления чужого подключения.

Состояние бота в памяти: перезапуск сбрасывает диалоги, переменные и лимиты. Один процесс на токен. Действия одного пользователя упорядочены; при включённой защите callback, поступивший во время обработки предыдущего действия, игнорируется. Удаление и обновление зависят от прав Telegram: при отказе бот продолжает работу. Для многих пользователей понадобится постоянное хранилище и управление временем жизни сессий.

`npm test` дополнительно проверяет совпадение Python/JS на сценариях с кнопками, вводом, условиями, командами, таймером, лимитом, сбросом и циклом; ZIP, синтаксис обоих языков, обработчики отправки/редактирования, отказ редактирования и защиту от повторных callbacks. Для запуска всех тестов на машине разработчика нужны `python3`, Go 1.22+ с поддержкой race detector и зависимости из `npm install`. TypeScript-компилятор устанавливается через npm. Реальная отправка в Telegram с токеном не проверялась.

## Языки экспорта

Список языков и команды запуска определены в `public/languages.js`; API и интерфейс используют один каталог. Установка Go или Python на сервере BotForge не требуется для генерации архива.

| Язык | Что в ZIP | Запуск из папки архива |
| --- | --- | --- |
| Python | `bot.py`, `runtime.py`, проект и настройки | `python3 bot.py` |
| JavaScript | `bot.js`, `runtime.js`, проект и настройки | `node bot.js` |
| TypeScript | `bot.ts`, общий JS-движок с декларациями типов, `package.json`, `tsconfig.json` | `npm install`, `npm run build`, `npm start` |
| Go | `main.go`, `runtime.go`, `go.mod`, проект и настройки | `go run .` |

Go 1.22+ использует только стандартную библиотеку. TypeScript работает на Node.js 20+, компилируется в строгом режиме и использует тот же движок, что предпросмотр и JavaScript-экспорт. Для TypeScript нужны бесплатные пакеты TypeScript и типы Node.js; версии зафиксированы в экспортированном package.json. Во всех архивах токен добавляется пользователем в локальный `.env`.

Go проверяется сборкой, `go test -race`, сопоставлением событий с предпросмотром и диалогом против тестового Telegram API. TypeScript проверяется компиляцией, исполнением собранного движка и запуском без токена с понятной ошибкой. Реальный Telegram с токеном для новых языков не проверялся.

## ИИ-помощник и раскладка

В конструкторе «ИИ» открывает описание желаемого бота. После явной отправки запрос с текущей схемой поступает в настроенный API, а сервер проверяет результат. Предложение показывает блоки и связи; «Применить» заменяет блоки, связи и переменные черновика. Проект не сохраняется автоматически. Доступна отмена последнего ИИ-изменения или раскладки. Если во время запроса схема изменилась, устаревшее предложение не применяется.

«Расставить» выстраивает имеющиеся блоки по уровням, сохраняет содержимое и соединения, обрабатывает циклы и отдельные ветки. Этот режим работает локально, без оплаты и API.

Ключ задаётся через `AI_API_KEY`, базовый URL через `AI_BASE_URL`, модель через `AI_MODEL`. По умолчанию провайдер — triklz27.ru, модель — gpt-6-luna. Ключ не попадает в браузер, генерируемые боты или Git. Не помещайте токены и личные данные в описание и схему: они отправляются внешнему провайдеру при генерации. Запрос использует баланс API.

Проверены ограничения запросов, невалидные ответы модели, отсутствие ключа в публичных данных, HTTPS-origin, сохранение черновика и раскладка циклической схемы. Реальный API проверен генерацией связанного сценария.

Генерация запрашивает JSON-режим и низкий объём рассуждений. Ответ с `finish_reason=length` не применяется. Пояснения вокруг одного полного JSON допускаются, но несколько сценариев или незавершённый JSON отклоняются без изменения проекта.

## Проверки SQLite и редактора

`node --test test/storage.test.js test/editor.test.js test/api.test.js` проверяет перенос и откат JSON-миграции, повторный запуск без повторного импорта, конфликт записи через два подключения SQLite, перестановку кнопок с выполнением перехода, переподключение обоих концов и поиск без изменения проекта.

Ручная проверка редактора: найдите блок по тексту, выберите результат и проверьте выделение/центрирование. В блоке с кнопками поменяйте порядок, сохраните, обновите страницу и проверьте диалог. Перетяните конец линии на другой блок, затем её начало на свободный выход. Попробуйте занятый выход и пустое поле: старая связь должна остаться. Проверьте переходы через свойства на телефоне. Новые действия требуют отдельной визуальной приёмки: Chromium в текущей среде не запускается.

В текущем прогоне прошли 29 тестов API, SQLite, редактора, ИИ, предпросмотра и Python/JavaScript-экспорта, а также отдельный тест компиляции TypeScript. Синтаксис и сборка редактора проверены. Полный `npm test` ограничен средой: установленная команда `go` не является компилятором Go, поэтому Go-проверка завершается до сборки. Реальный Telegram не проверялся.

## ИИ в текущем редакторе

Для существующего проекта по умолчанию используется «Изменить текущий». Модель получает выбранный блок и ID существующих связей и предлагает частичные правки. Сервер сохраняет неупомянутые элементы, координаты старых блоков и ID переподключённых выходов. Новые блоки размещаются отдельно без наложения на старые. Удаление возможно только по явным спискам ID/имён в предложении модели.

Перед применением показана сводка добавленных, изменённых и удалённых блоков, связей и переменных. «Создать заново» — отдельный режим полной замены. Обе операции доступны для отмены и не сохраняются автоматически. Изменившийся во время генерации черновик не перезаписывается. Поиск блоков, перестановка кнопок, переподключение линий и SQLite сохраняются.

`POST /api/projects/:id/ai` дополнительно принимает `mode: "edit" | "create"` и необязательный `selectedNodeId`. Ответ содержит полный проверенный результат и `changes` со списками `added`, `updated`, `removed` для блоков, связей и переменных. При `edit` JSON модели содержит только upsert-элементы в `nodes`, `edges`, `variables` и необязательные `removeNodeIds`, `removeEdgeIds`, `removeVariableNames`.

## Редактор и обучение

Блоки переносятся из левой панели на полотно либо добавляются нажатием. «Основные» показывают старт, текст и кнопки; «Расширенные» — команды, ввод, условия и завершение. Справа переключаются свойства и интерактивный чат. На телефоне панели открываются отдельными вкладками.

«Пройти обучение» создаёт отдельный пустой учебный проект. Подсказка подсвечивает элемент и показывает указатель; следующий шаг открывается после реального действия: добавить старт и текст, написать ответ, соединить, запустить чат, сохранить. Закрытие обучения оставляет проект в списке.

На пустом полотне «Создать и расставить» сразу применяет проверенный ответ ИИ и сохраняет новый проект. Для существующей схемы остаётся просмотр правок. «Спросить» объясняет сценарий без его изменения. Во время запроса показан индикатор ожидания; после получения и проверки ответа блоки появляются с анимацией. Частичный непроверенный JSON на полотно не попадает. Отключение анимации учитывает системное предпочтение reduced motion.

ИИ может один раз исправить JSON или связи по ошибкам валидатора в пределах общего таймаута 3 минуты. Автоматические циклы без ввода/кнопок отклоняются. Сценарии ограничены поддерживаемыми блоками: платёжные, HTTP, базы данных и уведомления администратору пока не реализованы. Нужные ручные действия модель должна пояснить в кратком итоге.

Google-вход подготовлен, но включается только после настройки OAuth-приложения владельцем. Настройка и ограничения бесплатных запросов описаны в [инструкции развёртывания](deploy/README.md).
