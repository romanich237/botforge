# BotForge

Первый этап: минимальный интерфейс конструктора Telegram-ботов.

Запуск: Node.js 20+, `npm start`, открыть http://localhost:3000.

Данные проектов сохраняются только в localStorage этого браузера. API, выполнение сценариев и экспорт пока не подключены. Предпросмотр является макетом.

План развития см. ROADMAP.md.
